Project Overview

TiT is a full-featured, multi-tenant Institute Management System. It serves as a central hub for educational institutes to manage students, teachers, classes, and administrative tasks efficiently. The system is designed with scalability and real-time interaction in mind.

Core Modules

1. Multi-Tenant Architecture

Built to host multiple schools/institutes under a single platform. Each tenant has isolated data and branding.

  • Super Admin: Global control, institute onboarding.
  • Tenant Admin: Institute-wide management and reports.

2. Dynamic Virtual Classrooms

Deep integration with Zoom for automated meeting creation and attendance tracking.

3. Academic Management

Includes a sophisticated Timetable system, Assignment management, and Learning Material distribution.

4. Messaging System

Internal communication layer for direct chat and system-wide announcements.
